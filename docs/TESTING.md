## 3. Протокол: curl против mock-сервера

Запуск: `node scripts/mock-server.mjs` (8 треков, токен `demo-token-123`).

```bash
curl -i -H "Authorization: Bearer demo-token-123" \
  -H "Range: bytes=100-200" \
  http://127.0.0.1:8765/audio/0101010101010101010101010101010101010101
```

Фактический результат:

```
HTTP/1.1 206 Partial Content
Accept-Ranges: bytes
Content-Range: bytes 100-200/352844
Content-Length: 101
Content-Type: audio/wav
```

Дополнительно:

- `GET /health` без токена → 200 JSON `{ok:true,...}`;
- `GET /library` без токена → 401 JSON;
- `GET /library` с токеном → каталог, пагинация, `version`;
- `GET /cover/{id}` → 200 `image/png`;
- `POST /debug/bump` → версия +1, SSE-событие получено приложением.

### Найденные и исправленные дефекты

- `coverId` mock-сервера был строкой — Rust ожидает число, каталог не парсился.
  Исправлено на числовой id.
- mDNS выбирал адрес VPN-адаптера. Добавлен выбор приватного адреса, совпадающего
  с /24 локального маршрута.
- mpv с `--keep-open=no` не присылал `eof-reached`; добавлена обработка IPC
  `end-file` (eof → следующая дорожка, error → понятное сообщение).
- Некэшированный трек в офлайне пытался открыть URL и зависал. Добавлена проверка
  `online` до play и сообщение «телефон недоступен, трека нет в кэше».
- Окно обрезалось справа/снизу при масштабе 125%: logical 1280×820 превращался в
  1600×990 physical на экране 1536×864, player bar уходил за экран. Добавлен
  Windows manifest с PerMonitorV2 и DPI awareness, окно 1200×620 (min 960×560).
  После исправления весь UI виден.

## 7. Что не проверено и почему

1. **Реальный Android.** Нет устройства/эмулятора. Не проверены: выдача разрешений,
   MediaStore на реальной библиотеке, foreground-сервис, уведомление, mDNS с
   телефона, QR-экран, поведение при выключенном экране 30+ минут.
2. **Тайминги первого play.** Требуется реальный телефон и LAN; измерение на
   localhost нерепрезентативно. Функционально play и кэш работают.
3. **20 000 треков.** Виртуализация и SQL-поиск реализованы, но нагрузочный прогон
   на 20k записей не выполнялся. Мок — 8 треков.
4. **Установщики.** Сборка бандлов зависит от наличия WiX/NSIS; см. результат
   release-сборки ниже.
5. **Кроссплатформенность.** Проверено только на Windows 11. Код для Linux/macOS
   (пути, Unix socket, команды открытия каталога) написан, но не запускался.
